# CREATE WORLD — CI-1 INTENT IMPLEMENTATION

## Purpose

This document defines the implementation contract for the first implementation
slice of `Creative Initiation`.

It is the agreement between Product and Engineering.

Its purpose is to ensure that engineering expresses the creator experience
rather than inventing it.

> CI-1 is not responsible for helping the creator create.
>
> It is responsible for helping the creator understand what they want to
> create.

## Implementation Hypothesis

Creative Initiation begins when Dropple helps the creator recognize and commit
to what they want to bring into existence before asking how they want to build
it.

## Constitutional Truth

Intention precedes language. Language precedes method. Method precedes
creation.

CI-1 exists because the creator cannot choose a language until they understand
their intention.

## Trigger

CI-1 begins when the creator chooses to begin creating.

This is a product trigger, not a technical event.

It is not defined by:

- opening an editor
- entering a canvas
- selecting a Blueprint
- selecting a Template

## Creator Realization

`I understand what I want to create.`

This is the only psychological outcome CI-1 is allowed to pursue.

CI-1 must not attempt to answer:

- how to create it
- which language expresses it
- which Blueprint should begin it
- which Template should begin it

Those belong to later slices.

## Scope

### In Scope

CI-1 may help the creator:

- recognize intention
- clarify intention
- reflect on intention
- gain confidence in intention

### Out of Scope

CI-1 must not introduce:

- Creative Language selection
- Blueprint selection
- Template selection
- canvas
- project creation
- workspace
- runtime concepts
- editor UI
- file management
- technical configuration

Those belong to `CI-2`, `CI-3`, or `CI-4`.

## Freeze Condition

CI-1 is complete when the creator can honestly say:

`I understand what I want to create.`

It is not complete when the creator merely says:

- `I know which language.`
- `I picked a Blueprint.`
- `I picked a Template.`
- `I opened the editor.`

The only valid freeze condition is:

`I understand what I want to create.`
