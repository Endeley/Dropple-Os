# CREATE WORLD — STAGE 1: CREATIVE INITIATION IMPLEMENTATION PLAN

## Purpose

This document defines the implementation-planning slice sequence for
`Creative Initiation`.

It does not design screens, choose components, or prescribe UI structure.

Its job is to define the creator realizations that must be implemented one at a
time before the chapter can be considered complete.

## Implementation Planning Rule

Each slice must prove one creator realization before the next slice opens.

No slice may:

- invent product behavior outside the accepted chapter plan
- collapse multiple realizations into one implementation by convenience
- introduce technical choices before the creator meaning is clear

## Slice Sequence

### CI-1 — Intent

#### Creator Realization

`I understand what I want to create.`

#### Slice Responsibility

This slice establishes the first moment of creator clarity.

Dropple should help the creator identify intent without requiring them to think
in terms of applications, files, or editors.

#### Validation Target

The creator can truthfully say:

`I know what I want to create.`

---

### CI-2 — Language

#### Creator Realization

`I know which creative language expresses it.`

#### Slice Responsibility

This slice maps creator intent into creative language.

Dropple should help the creator understand the language of creation they are
entering, rather than presenting software categories or technical surfaces.

#### Validation Target

The creator can truthfully say:

`I know which creative language I am entering.`

---

### CI-3 — Starting Method

#### Creator Realization

`I know the best way to begin.`

#### Slice Responsibility

This slice reveals the lawful starting path for the chosen language.

For system-shaping languages, that path may be a `Creative Blueprint`.

For expression-shaping languages, that path may be a `Template`.

This slice should preserve the constitutional rule that starting method follows
language.

#### Validation Target

The creator can truthfully say:

`I understand how this kind of creation should begin.`

---

### CI-4 — Commitment

#### Creator Realization

`I am ready to enter the Living World.`

#### Slice Responsibility

This slice completes Creative Initiation.

It confirms the creator's chosen beginning and hands off into
`Creative Arrival` without feeling like another application, setup wizard, or
project manager.

#### Validation Target

The creator can truthfully say:

`I know exactly how I want to begin.`

At that point:

- `Creative Initiation` ends
- `Creative Arrival` begins

## Validation Discipline

Each implementation slice should be reviewed and validated independently before
the next slice opens.

The validation question for every slice is:

`Did this slice establish the intended creator realization without inventing new product truth?`

## Out of Scope

This implementation plan does not define:

- screen layouts
- component hierarchy
- animation behavior
- canvas behavior
- runtime implementation
- blueprint mechanics
- template mechanics

Those belong to later implementation work after the slice sequence is accepted.
