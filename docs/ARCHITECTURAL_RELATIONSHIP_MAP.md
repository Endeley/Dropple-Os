# ARCHITECTURAL RELATIONSHIP MAP

## Status

`DRAFT FOR REVIEW`

## Purpose

This document is not a new authority.

It does not redefine any constitutional, product, experience, language, or
world model.

It exists to answer one question:

`How do the existing Dropple authorities relate to one another?`

The architecture is not unclear because it is incoherent.

It is unclear because it is distributed.

This map makes those relationships explicit without replacing the source
documents that define them.

## Scope

This map does not:

- create new law
- replace existing law
- reconcile terminology by force
- reopen frozen authorities
- choose one document over another where multiple documents are speaking from
  different valid layers

It only identifies:

- what layer a document is speaking from
- what question it answers
- how it relates to neighboring layers

## Governing Interpretation

After reading the current Dropple corpus, the strongest stable principle is:

`Creation is continuous.`

A creator does not leave one creative environment to enter another.

The canvas persists.

The living world persists.

Creative Languages change how meaning is expressed, never where creation
exists.

This sentence is not introduced here as a new law.

It is recorded here as the clearest relationship statement that the existing
documents collectively reinforce.

## Authority Map

The current corpus can be read as the following relationship stack.

`Universal Canvas`

`-> Living World / First World / Create World`

`-> Creative Domain`

`-> Creative World`

`-> Creative Language`

`-> Grammar`

`-> Artifact`

`-> Capability Projection`

This is a relationship map, not a replacement ontology.

Each layer below exists inside the persistence of the layers above it.

## 1. Universal Canvas

### What It Is

The universal substrate of continuity.

### Question It Answers

`What remains continuous regardless of mode, language, artifact, or project state?`

### Stable Meaning

The canvas does not change.

It is the persistent surface of creation.

### Relationship Downward

The `Living World` and `Create World` are experienced within this canvas.

## 2. Living World / First World / Create World

### What They Are

The persistent world-bearing realities through which creation is experienced.

These terms appear in different documents because they answer different
questions at different scopes:

- `Living World` emphasizes continuity of existence
- `First World` emphasizes the arrival and orientation world at `/`
- `Create World` emphasizes the shared creative environment in which making
  happens

### Question They Answer

`Where does creation exist?`

### Stable Meaning

Creation happens inside one persistent world, not inside a sequence of
separate applications.

### Relationship Downward

Inside this persistent world, distinct `Creative Domains` may be encountered
without leaving the world itself.

## 3. Creative Domain

### What It Is

A major region of creative possibility.

Examples include directions such as:

- design
- UI/UX
- animation
- collaboration
- writing
- development
- audio
- AI

### Question It Answers

`What kind of creation is foregrounded here?`

### Stable Meaning

A `Creative Domain` is not a button, menu, or separate application.

It is a domain of creative possibility inside the same persistent world.

### Relationship Downward

Each `Creative Domain` contains or gives rise to a more specific `Creative World`
or conceptual making context.

## 4. Creative World

### What It Is

The mental universe or contextual making reality within a `Creative Domain`.

Examples from existing language models include contexts such as:

- `Application`
- `Composition`

### Question It Answers

`What kind of making-world does this domain open up?`

### Stable Meaning

This is the term most at risk of collision with `Create World` and
`Living World`.

However, in the current corpus it does not mean the persistent host world.

It means the internal contextual world of a discipline.

### Relationship Downward

Inside a `Creative World`, a `Creative Language` defines how the creator
thinks and what meaning structure is primary.

## 5. Creative Language

### What It Is

The semantic language through which a domain thinks, creates, and progresses.

Examples from current documents include languages such as:

- Graphic
- UIUX

### Question It Answers

`How does this discipline think inside the shared world?`

### Stable Meaning

`Creative Language` owns discipline-specific meaning.

It does not own the persistent host world.

It does not create a separate canvas.

It changes how meaning is expressed within the same continuity.

### Relationship Downward

A `Creative Language` is made concrete through its `Grammar`.

## 6. Grammar

### What It Is

The stable conceptual structure through which a `Creative Language` forms
meaning.

Examples:

- `Composition -> Group -> Object -> Style -> Effect`
- `Application -> Page -> Section -> Component`

### Question It Answers

`What are the primary meaning relationships inside this language?`

### Stable Meaning

Grammar defines how thought is organized before low-level tooling is
considered.

### Relationship Downward

Grammar gives meaning shape to artifacts.

## 7. Artifact

### What It Is

A concrete thing the creator brings into existence inside a language.

Examples:

- artboard
- page
- group
- text
- vector

### Question It Answers

`What meaningful thing now exists?`

### Stable Meaning

Artifacts are not the world.

They are expressions inside the world.

### Relationship Downward

Artifacts become perceivable and operable through capability projection.

## 8. Capability Projection

### What It Is

The creator-facing projection of what can be done, understood, adjusted, or
next brought into being.

### Question It Answers

`What capabilities are relevant here now, given the current language, grammar, and artifact state?`

### Stable Meaning

Capability projection is downstream of meaning.

It should reveal relevant possibility.

It must not replace the semantic structure above it.

## Known Terminology Pressure

This map records one meaningful pressure point without resolving it here.

### Pressure Point

`Creative World`

This phrase appears to be used in two different senses across the repo:

1. as a discipline-level contextual universe inside a `Creative Domain`
2. as part of the broader family of terms that also includes `Living World`,
   `First World`, and `Create World`

This document does not resolve that naming pressure.

It only records it.

## Operating Reading Rule

Until a lawful terminology reconciliation occurs, existing documents should
be read with the following discipline:

- if a document is describing persistence, continuity, entry, or host
  existence, it is speaking about the shared world layer
- if a document is describing discipline-specific meaning, grammar, starter
  semantics, or capability framing, it is speaking about the language layer
- if a document is describing relationships between kinds of creativity, it
  is likely speaking about domains

## Essence

Dropple is best understood not as competing architectures, but as layers
speaking different truths about one continuous creative reality.

## Memory

The reader should remember that the architecture is distributed, not broken.

The same idea is often being reinforced from different layers rather than
contradicted.

## Creative Directives

- Do not invent a new authority when a relationship map is sufficient.
- Do not reconcile terminology prematurely by flattening valid layered
  distinctions.
- Read each document by the question it answers before judging its wording.
- Preserve the continuity principle above all: creation remains inside one
  persistent creative reality.
