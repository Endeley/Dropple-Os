# Graphic Creative Journey

## Purpose

This document defines the first mental journey of a Graphic creator inside Dropple.

It does not define UI implementation.
It does not define shell extraction.
It does not define runtime behavior.

Its purpose is to answer:

`What should a Graphic creator understand, feel, and want to do during the first 30 seconds?`

This document sits before:

- empty-world expression
- first-artboard expression
- tool exposure

The goal is to begin with thought, not interface.

## Governing Shift

Graphic is no longer an inheritance problem.

It is now a product-design problem.

The key question is no longer:

`Where does Graphic live?`

It is:

`How does a Graphic creator think when they begin visual communication work?`

## Core Rule

Never begin with tools.

Begin with thought.

Graphic should not first communicate:

- shape
- vector
- toolbar
- canvas controls

Graphic should first communicate:

- you are here to communicate something visually
- you are creating a visual composition
- this composition can become a meaningful communication artifact
- you can begin from intention without filling out setup forms

## The Creator's First Thought

Graphic creators do not begin by thinking about geometry.

They begin by thinking about communication.

Typical first thoughts include:

- I need to tell people something
- I need to promote something
- I need to explain something
- I need to present something
- I need to express an identity

Dropple should respond to those thoughts before introducing:

- composition
- artboards
- tools

## Creative System Reading

Internal model:

`Intent`

`-> Communication`

`-> Composition`

`-> Artifacts`

`-> Elements`

Creator-facing model:

`Communication`

`-> Composition`

`Composition`

`-> Artboards`

`-> Objects`

This means the first experience should introduce:

- the communication need
- the composition system
- then the first bounded expression
- then the local building blocks

Not the reverse.

## The First 30 Seconds

### 1. What the creator should understand

Within the first few seconds, the creator should understand:

- I am here to communicate something visually
- I am creating a visual composition
- this is not a generic drawing surface
- I can begin from a meaningful communication direction
- I do not need to configure everything before starting

### 2. What the creator should feel

The creator should feel:

- invited
- oriented
- creatively capable
- not trapped in a tool-first editor

The experience should reduce fear of choosing incorrectly.

### 3. What the creator should want to do next

The creator should naturally want to:

- express a communication goal
- start a composition
- choose a communication direction
- place the first bounded expression inside that composition

Not:

- pick a primitive tool
- stare at an empty grid
- decide between low-level geometry operations

## Composition Before Artboard

This is the most important product rule for Graphic:

`Communication is the visible need.`

`Composition is the owner.`

`Artboards are bounded expressions inside a Composition.`

This means the experience should not revolve around:

`canvas -> artboard -> objects`

It should revolve around:

`communication -> composition -> artboards -> objects`

`composition -> artboards -> objects`

Artboards matter.
They are not the center of the language.

Composition is.

## Starter Thought

Graphic should begin with communication directions rather than isolated tools.

The creator's likely opening thoughts are closer to:

- I want to make a poster
- I need a social graphic
- I’m assembling a brand board
- I want a presentation cover

They are not usually:

- I want to place a rectangle
- I want to start with a vector path

This means the first experience should bias toward:

- Poster
- Social Graphic
- Brand Board
- Logo Sheet
- Flyer
- Presentation Cover

These are communication intents expressed through Graphic language.

Dropple's job is not to force the creator to name the full system up front.

Dropple's job is to recognize:

- the creator has a communication need
- composition is the first structured response to that need
- artboards and objects serve that composition

## Progressive Revelation

Graphic should infer more than it asks.

The creator should not start with forms for:

- audience
- tone
- message
- outputs
- goals

Instead:

`Create`

`-> Observe`

`-> Understand`

`-> Guide`

This keeps the first experience fluent while preserving deeper semantic guidance later.

## Conclusion

The first Graphic experience should help the creator think:

`I want to communicate something visually.`

Then:

`Great. Let's build a Composition.`

Then:

`Inside this Composition, I can create meaningful communication artifacts.`

Then:

`Now I need an Artboard to express this composition.`

That is the correct mental order for the start of Graphic in Dropple.
