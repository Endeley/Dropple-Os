# Dropple v1 — Dropple‑Custom Tools × UI Layers (Canonical Overlay)

## Overlay Rules (Locked)
- Dropple‑custom tools never replace foundational tools
- They augment interpretation, not structure
- Same tool may appear in multiple layers, but with different depth
- v1 = surface + illusion, not full power
- Capability rules still apply underneath

---

## Left Sidebar
**Structural · Intent Layer**
(“What kind of thinking am I doing?”)

Dropple‑custom tools appear here only if they change authoring intent, not details.

### 1. State Composer (v1: entry point only)
**Surface in v1**
- A single tool entry: “States” or “State Transitions”

**What it does in v1**
- Lets user define states (Idle / Hover / Active / Scene A / Scene B)
- Does not expose timelines or keyframes
- Uses Ghost Preview only

**Layer reason**
- It changes how the user thinks, not properties

Deep motion editing is locked (v2).

---

### 2. Time Lens (v1: subtle)
**Surface in v1**
- Minimal time scrub affordance
- No tracks, no curves

**What it does**
- Preview state changes
- Preview interactions
- Preview templates

**Layer reason**
- Time becomes a mode of viewing, not editing

---

## Right Sidebar
**Structural · State / Inspector Layer**
(“What is this thing?”)

Dropple‑custom tools show up here as assistive intelligence, never as replacements.

### 3. Intent Dial (v1: read‑only + suggest)
**Surface in v1**
- Small “Intent” section
- Labels like: Calm ↔ Energetic, Soft ↔ Sharp

**What it does in v1**
- Shows detected intent
- Suggests changes
- Uses Ghost Preview only

No auto‑apply in v1.

---

### 4. Explain / Fix / Extend (v1: Explain only)
**Surface in v1**
- Inspector button: “Why does this feel like this?”

**What it does**
- Explains layout / motion / interaction decisions
- No mutation
- No auto‑fix

**Layer reason**
- Inspector is where understanding lives

---

### 5. Component Memory (v1: passive)
**Surface in v1**
- Read‑only metadata in Inspector
- Shows: known states, past usage hints

**What it does**
- Improves Explain quality
- Builds foundation for v2 reuse intelligence

---

## Floating UI
**Contextual / Ephemeral Layer**
(“Do this faster / see this now”)

This is where Dropple feels magical — but we keep it tight.

### 6. Ghost Preview (v1: visual‑only)
**Surface in v1**
- Hover previews
- Soft overlays
- No commit buttons

**Used for**
- Layout suggestions
- State transitions
- Intent suggestions
- Template previews

**Why floating**
- It’s an illusion
- It must feel temporary

This is the strongest Dropple differentiator in v1.

---

### 7. Quick Actions (already locked)
Floating, contextual, one‑click:
- Duplicate
- Delete
- Align Center
- Wrap in Frame
- Group
- Ungroup

Dropple‑custom tools do not add more actions here in v1.

---

### 8. Visual Balance Hints (v1: passive)
**Surface**
- Subtle visual indicators (edges, weight hints)
- No UI chrome
- No controls

**What it does**
- Helps users see imbalance
- Explains “why this feels off” visually

---

## Not Surfaced in v1 (Architecturally Present)
These exist conceptually but stay dormant:
- Animate Between States (full power)
- Intent‑first free‑text commands
- AI Fix / Extend
- Motion Doctor
- Loop Architect
- Story Cutter
- Brand Gravity controls
- Variant Matrix
- Token‑driven motion editor

They rely on deeper capability unlocks, user trust, and stronger mental models.

---

## Final Mental Map (Lock This)
- Left → Intent & Thinking
- Right → Truth & Explanation
- Floating → Speed & Illusion

Dropple‑custom tools:
- Interpret
- Explain
- Preview
- Suggest

They never directly mutate in v1.

---

## Why This Overlay Is Strong
- Keeps v1 shippable
- Preserves the full Dropple vision
- Avoids UI overload
- Avoids doubles
- Avoids lying UI
- Makes v2 a natural unlock, not a rewrite
