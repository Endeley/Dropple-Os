# Implementation Roadmap V2

Status: execution governance  
Authority: subordinate to `docs/LAW.md`

## Purpose

This roadmap defines strict phase progression for decade-scale Dropple architecture hardening.

Progression is fail-closed:

1. no phase advancement without dependency closure
2. no phase marked complete without gate pass
3. no broad product-workspace expansion before `R7`

1. `R0` Governance Lock
2. `R1` Replay Scale Core
3. `R2` Event Log Durability
4. `R3` Projection Performance
5. `R4` Collaboration Federation Determinism
6. `R5` Media Cinema Schema Canonicalization
7. `R6` Capability Overlay Unification
8. `R7` Product Workspace UI Buildout

Full user-facing workspace/mode product expansion starts at `R7` only.

Before `R7`, UI work is limited to constitutional, diagnostic, and deterministic embodiment surfaces required to close earlier phases.
