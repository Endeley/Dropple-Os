# Create World Transition Roadmap

## Purpose

This document defines the Living Create World transition roadmap.

It is not a UI specification.
It is not a shell plan.
It is not an implementation log.

Its purpose is to bridge:

- the Create World experience model
- transition slice planning
- validated implementation evidence

This roadmap exists to support experience-first implementation inside one persistent creative world.

## Governing Rule

This roadmap is not organized around screens or components.

It is organized around creator transitions.

Each slice must answer:

- which creator state is being completed
- which next creator state is being entered
- what behavior proves the world responded
- what evidence must be recorded before the slice is frozen

## Scope

This roadmap covers the first Living Create World transition sequence only.

It does not define:

- broad shell redesign
- runtime redesign
- projection architecture changes
- language-specific deep editing behavior

Those remain separate constitutional or language-specific concerns.
