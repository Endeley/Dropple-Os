# Graphic Projection Model

## Purpose

This document defines how the Graphic language becomes visible to creators.

It does not define a new shell.
It does not define a new world.
It does not define implementation details.

Its purpose is to answer:

`How should the Graphic dictionary appear to creators through shared Create World surfaces?`

This document follows the same semantic projection discipline already proven in UIUX:

- identity becomes visible
- meaning becomes visible
- evolution becomes visible
- next meaningful steps become visible
- capability domains become visible

The language model defines how Graphic thinks.
The dictionary defines what Graphic can say.
This projection model defines how Graphic should speak.

## Governing Rule

Graphic projection should make creators feel:

`I am building a composition`

before they feel:

`I am editing objects`

That is the primary projection law for Graphic.

## 1. Projection Owner Split

Graphic projection follows the frozen activation ownership model:

- Create World Shell exposes projection surfaces
- Product Expression presents projection surfaces
- Graphic Language provides projection content

This means:

- Create World decides where a projection may appear
- Product Expression decides how it feels
- Graphic decides what it means

## 2. Projection Entry Conditions

Graphic projection should emerge by context.

### Empty World

Projection should help the creator understand:

- what world they are in
- what the first artifact is
- which meaningful starting directions exist

### First Artboard Created

Projection should help the creator understand:

- what an artboard is
- what belongs on it
- what the next visual decision is

### Object Selected

Projection should help the creator understand:

- what this object contributes to the composition
- what it can become
- what should happen next

### Multiple Objects Selected

Projection should help the creator understand:

- this is now a composition structure problem
- grouping and arrangement are relevant

### Motion Attached

Projection should help the creator understand:

- time has become meaningful
- motion is now part of the composition language

## 3. Projection Shape

Each Graphic projection should answer the same five questions:

1. Identity
2. Meaning
3. Evolution
4. Next Meaningful Steps
5. Capability Domains

That is the canonical projection shape.

## 4. Artboard Projection

When an `Artboard` is selected, the creator should see:

### Identity

`Artboard`

This is an Artboard.

### Meaning

## 12. Starter Projection

Starter semantics should also be projectable.

The creator should not only see starter cards.
They should feel the language behind the starters.

### Poster Projection

Meaning:

A communication piece designed to attract attention and convey a message quickly.

Momentum:

- Define focal message
- Create hierarchy
- Introduce imagery
- Establish color system

### Brand Board Projection

Meaning:

A composition that defines and communicates a visual identity system.

Momentum:

- Define palette
- Select typography
- Create brand assets
- Establish consistency

### Social Graphic Projection

Meaning:

A composition designed for fast communication inside a social feed context.

Momentum:

- Establish focal point
- Optimize readability
- Balance image and message
- Reinforce brand identity

### Logo Sheet Projection

Meaning:

A composition used to organize, compare, and present logo forms and variations.

Momentum:

- Compare variants
- Refine proportions
- Check consistency
- Prepare approved marks

### Flyer Projection

Meaning:

A compact communication piece designed to inform and persuade quickly.

Momentum:

- Clarify message
- Build hierarchy
- Add supporting assets
- Prepare for distribution

### Presentation Cover Projection

Meaning:

A composition that introduces a presentation with clarity, tone, and identity.

Momentum:

- Establish tone
- Introduce title hierarchy
- Add supporting visual
- Define presentation identity

## 13. Projection Tone Rules

Graphic projection should follow these tone laws:

- reveal meaning before properties
- reveal composition before controls
- reveal hierarchy before formatting
- reveal message before tooling
- reveal direction before detail

Graphic projection should never feel like:

`generic object inspection`

It should feel like:

`guided visual composition`

## 14. Empty World Implication

This projection model gives Graphic enough semantic structure to support a future empty-world expression.

That future experience should likely communicate something like:

`Create a Visual Composition`

`Everything starts with an Artboard`

with starter directions such as:

- Poster
- Social Graphic
- Brand Board
- Logo Sheet
- Flyer
- Presentation Cover

This document does not define that screen.
It defines the projection logic that would make that screen truthful.

## 15. Conclusion

Graphic projection should make the creator experience:

- composition
- hierarchy
- message
- style
- direction

before editor operations.

That is how Graphic can feel like Graphic while still living inside the same Create World.
