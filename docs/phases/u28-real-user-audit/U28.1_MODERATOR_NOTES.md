# U28.1 Moderator Notes

## Rules

- Do not explain the product
- Do not define:
  - Universe
  - Room
  - Perspective
  - Workflow
  - Creative OS
- Do not teach
- Do not correct
- Do not rescue minor confusion
- Only intervene if the session cannot continue

If asked what to do:

> Do whatever feels most natural.

If asked what something means:

> Tell me what you think it means.

## Success Signals

Participant identifies:

- A project
- A current location
- A plausible next action
- A persistent object that survives the session

Participant naturally describes:

- One project
- Multiple perspectives

rather than:

- Multiple tools
- Multiple applications

## Failure Signals

Participant believes:

- They are switching apps
- The project is not the primary object
- The UI is temporary
- The system requires explanation to start

## Most Important Observation

Do they see:

One Project -> Many Perspectives

or:

Many Tools -> Many Pages

This is the primary Creative OS validation signal for U28.1.
