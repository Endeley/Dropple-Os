# U28.1 Participant Screener

Use this screener to recruit first-time participants for the `U28.1 First-Time User Orientation` audit.

Goal: find people who can react to Dropple without prior model contamination.

## Recruiting Goal

Recruit:

- first-time users
- mixed backgrounds
- people comfortable thinking aloud

Recommended first cohort:

- 5 participants minimum
- 7-10 participants preferred

Recommended mix:

- 1-2 non-technical users
- 1-2 creative professionals
- 1-2 designers
- 1-2 developers or technical builders
- 1 product/generalist participant if possible

## Hard Requirements

Participant must:

- be 18 or older, if required by your research policy
- have no hands-on Dropple experience
- be willing to think aloud
- be willing to use an unfamiliar product without guidance

Participant must not:

- have worked on Dropple
- have been taught the Dropple architecture
- have seen internal roadmap or audit materials

## Screener Questions

Ask these before booking.

### 1. Prior Familiarity

Have you used Dropple before?

- [ ] No
- [ ] I have heard of it but never used it
- [ ] Yes

Reject if:

- `Yes`

### 2. Product Exposure

Have you seen demos, walkthroughs, or internal explanations of Dropple?

- [ ] No
- [ ] Maybe briefly
- [ ] Yes

Prefer:

- `No`

Use caution if:

- `Maybe briefly`

Reject if:

- `Yes`, if the exposure was substantial

### 3. Background

Which best describes you?

- [ ] Non-technical
- [ ] Creative professional
- [ ] Designer
- [ ] Developer
- [ ] Product manager
- [ ] Student
- [ ] Other: __________

### 4. Familiar Tools

Which of these have you used regularly?

- [ ] Figma
- [ ] Canva
- [ ] Framer
- [ ] Notion
- [ ] Miro
- [ ] GitHub
- [ ] Linear / Jira
- [ ] Adobe tools
- [ ] None of these
- [ ] Other: __________

Purpose:

- capture comparison bias, not reject

### 5. Comfort With New Software

How comfortable are you trying unfamiliar software with no instructions?

- [ ] Very comfortable
- [ ] Somewhat comfortable
- [ ] Not very comfortable

Prefer a mix.

### 6. Think-Aloud Comfort

Are you comfortable speaking your thoughts out loud while using a product?

- [ ] Yes
- [ ] Somewhat
- [ ] No

Reject if:

- `No`

### 7. Availability

Are you available for a 20-30 minute recorded usability session?

- [ ] Yes
- [ ] No

Reject if:

- `No`

## Selection Notes

Prefer participants who:

- have no prior Dropple exposure
- represent different mental models
- will naturally compare Dropple to existing tools

Avoid overloading the cohort with only:

- designers
- developers
- highly technical internal-adjacent users

The goal is not expert validation.

The goal is first-time orientation evidence.

## Moderator Reminder

Do not explain the product before the session.

Do not send:

- architecture notes
- product walkthroughs
- onboarding materials
- screenshots with labels

Recruitment itself must preserve the first-time condition.
