# ARR2.1 Truth

## Status

`FROZEN`

## Phase

`ARR2.1 - Truth`

## Authority

`Constitutional`

## Date

`July 22, 2026`

## Purpose

Define the constitutional nature of `Revelation` independently of:

- implementation
- runtime
- user interface
- interaction design
- representation

This artifact answers one question only:

`What does it mean for world knowledge to become knowable?`

## Constitutional Definition

`Revelation` is the constitutional subsystem that governs when existing
world truth becomes knowable to a traveler.

It does not:

- create world truth
- modify world truth
- reinterpret world truth
- replace world truth

`Revelation` is a relationship of access.

It is not a source of truth.

## Frozen Constitutional Truths

### Truth 1 - World Truth Exists Before It Is Known

Knowledge may exist in the `World` before it is knowable to a `Traveler`.

World truth is independent of observation.

Existence is not contingent on discovery.

### Truth 2 - Revelation Does Not Create Knowledge

`Revelation` governs the transition from `unknown` to `knowable`.

It introduces no new:

- entities
- meanings
- relationships
- semantics

It governs only access to what already exists.

### Truth 3 - Knowability Is Relational

Knowability belongs to the relationship between `Traveler` and `World`,
not to the `World` alone.

The `World` remains unchanged.

The `Traveler's` state of understanding changes.

### Truth 4 - Revelation Is Traveler-Specific

Different `Travelers` may lawfully know different things about the same
unchanged `World`.

`Revelation` is therefore contextual to the `Traveler` without altering
world truth.

### Truth 5 - Revelation May Never Modify World Truth

`Revelation` may:

- expose
- defer
- conceal
- sequence

It may never modify world truth.

World authority remains absolute over:

- existence
- identity
- geography
- relationships
- semantics
- state

## Truth-Phase Implication

`Revelation` presupposes a subject capable of knowing.

This implies the emergence of a `Traveler` as a first-class participant in
the `Revelation` model.

At this stage:

- the `Traveler` is not yet a subsystem
- the `Traveler` is not yet part of the `World Pipeline`
- the `Traveler` is not yet a runtime construct

It is an ontological implication arising from the definition of
`Revelation` itself.

Its architectural treatment belongs later in `ARR2.1 Structure`.

This artifact defines what `Revelation` is.

It does not define:

- what subsystem owns `Revelation`
- what contracts `Revelation` has with adjacent layers
- how `Revelation` is implemented

- `ARR2.1 Behavior`
- `ARR2.1 Structure`

## Exit Criteria

`ARR2_1_TRUTH.md` is complete when it answers:

`What does it mean for world knowledge to become knowable?`

without prescribing how knowledge is revealed or represented.

## Constitutional Outcome

`Revelation` is now defined as an access relationship between `Traveler`
and existing `World` truth.

It preserves the authority established in `ARR2.0`:

`World -> Projection`

and prepares the next phase to define how `Revelation` behaves without
redefining what `Revelation` is.
